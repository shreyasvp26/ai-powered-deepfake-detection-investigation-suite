\section{Experimental Setup}

\subsection{Dataset}
We evaluate on FaceForensics++~\cite{rossler2019faceforensics}, which contains 1,000 original YouTube videos and corresponding fakes generated by four methods - Deepfakes, Face2Face, FaceSwap, and NeuralTextures (1,000 fake videos each). All experiments use c23 (light H.264) compression, the standard benchmark setting.

\subsection{Identity-Safe Splits}
Standard FF++ splits let the same source identity appear in both training and testing, which inflates attribution accuracy by roughly 2-5\%. To avoid this, we apply \textbf{source-ID-based partitioning}: every video sharing a source identity goes into the same split (80/10/10 train/val/test). We run a cross-check to verify that no training source ID leaks into the official test partition.

\subsection{Metrics}
\textbf{Attribution:} macro-F1 (primary), per-class precision/recall, one-vs-rest AUC.  \textbf{Detection:} binary AUC-ROC.  \textbf{Calibration:} Expected Calibration Error~\cite{guo2017calibration} before and after temperature scaling.  \textbf{Cross-dataset:} AUC on Celeb-DF~v2~\cite{li2020celebdf} and DFDC preview~\cite{dolhansky2020dfdc} subsets.
